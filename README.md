OHD Buildable Weapon

This repository contains Unreal Engine assets for a buildable weapon, the M2 Browning.

Demoing the Buildable Weapon

    Modify the construction tool for any faction
    Add the mod blueprint into one of the available slots
    Add a preview mesh, by using any from the mod folder

Controls

MMB : Fire
Default Aim Key : Aim in
F : Operate/Stop Operating

Key Features

    -Has dynamic rotation limits for obstacle collisions and overhangs
    -Character smoothly transitions between standing and crouched states based on pitch angle
    -Character can step up onto changes in terrain
    -ACOG Sight
